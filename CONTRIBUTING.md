# Contributing

Fairshift Lab welcomes small, evidence-backed changes.

1. Open an issue for new research scope or metric semantics.
2. Create a focused branch.
3. Add or update tests and documentation with the implementation.
4. Run `pytest`, `ruff check .`, `ruff format --check .`, `mypy src`, and `python -m build`.
5. Use English Conventional Commits and submit a draft pull request.

Never commit personal data, secrets, generated reports, model artifacts, or claims unsupported by the implemented experiment. Scientific changes must state assumptions, provenance, uncertainty, limitations, and the difference between evidence and interpretation.
